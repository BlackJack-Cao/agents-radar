# Agents Radar 个人收藏设计

## 目标

为静态 GitHub Pages 日报增加个人收藏能力。访问者可以收藏具体日报条目、查看自己的收藏列表、取消收藏，并从收藏列表跳回原报告条目。所有数据仅保存在当前浏览器的 `localStorage` 中，不增加登录、数据库或后端接口。

本次迭代只实现收藏，不实现备注。备注将在后续迭代独立设计和开发。

## 条目范围

页面在 Markdown 渲染完成后增强以下有实际内容的语义块：

- 顶层列表项，嵌套说明归入所属顶层条目；
- 章节内的独立正文段落；
- `<details>` 的 `<summary>` 项目摘要；
- 表格正文行。

不增强报告标题、章节标题、数据来源、生成时间、分隔线和自动生成页脚。

## 稳定标识

每条内容的 `itemId` 由以下部分生成：

- 日期；
- 报告 ID；
- 规范化后的条目定位文本哈希；
- 同文条目在当前报告中的重复序号。

收藏记录同时保存标题、摘要和 `anchorText`。即使后续报告内容调整导致无法精确定位，收藏列表仍能显示原始信息。

## 本地存储

使用存储键 `agents-radar-personal-items-v1`：

```json
{
  "version": 1,
  "items": {
    "2026-07-24/ai-medical/1abc-0": {
      "id": "2026-07-24/ai-medical/1abc-0",
      "date": "2026-07-24",
      "report": "ai-medical",
      "title": "bloodworks-io/phlox",
      "anchorText": "bloodworks-io/phlox 链接 ...",
      "snippet": "开源、本地优先的医疗 AI Agent ...",
      "favorite": true,
      "updatedAt": "2026-07-30T03:00:00.000Z"
    }
  }
}
```

读取时严格校验版本和字段。数据损坏时不自动覆盖，页面提示用户重置本地收藏。写入失败时保持原状态，并显示保存失败提示。

## 页面交互

- 每个可收藏条目显示星标图标按钮；桌面端在悬停、聚焦或已收藏时显示，移动端始终显示。
- 点击星标直接收藏或取消收藏，并同步更新页面按钮和顶部数量。
- 页头增加“我的收藏”入口，打开右侧抽屉查看全部收藏。
- 收藏按最近更新时间倒序排列，显示日期、报告名称、标题和摘要。
- 点击收藏记录后关闭抽屉并打开对应报告，优先通过稳定 `itemId` 精确定位原条目。
- 精确定位成功后展开所属 `<details>`、平滑滚动到屏幕中央，并使用独立高亮动画强调约 4 秒。
- 当日报内容变化导致 `itemId` 无法命中时，回退到现有 `anchorText` 文本匹配；仍找不到时打开报告并提示“条目内容可能已更新”。
- 多标签页通过 `storage` 事件同步收藏状态。

## 非目标

- 不实现备注、评论或公开收藏数；
- 不实现跨设备同步、导入导出或云端备份；
- 不修改 Markdown 日报、搜索索引、飞书推送或 GitHub Actions；
- 不引入登录、数据库和后端服务。

## 测试

- 单元测试覆盖 ID 稳定性、重复序号、数据校验、收藏切换、排序与输入不变性；
- 页面静态测试确认收藏模块、抽屉、稳定 ID 跳转、专用高亮和无障碍标签已接入；
- 浏览器验证桌面与移动端收藏、取消、刷新恢复、精确跳转、高亮和存储错误提示；
- 最终运行完整 Vitest、TypeScript、ESLint、Prettier 和差异检查。
